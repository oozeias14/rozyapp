🤖 Baixar para Android 🌐 Usar no navegador (todos os aparelhos)

📱 Instalando no iPhone

  1. Toque em "Usar no navegador" acima (abre no Safari)
  2. Toque no ícone de Compartilhar (o quadrado com a seta para cima)
  3. Escolha "Adicionar à Tela de Início"
  4. Pronto — o Amigos Dr Candido fica com ícone próprio, igual um app instalado

🤖 Instalando no Android

  1. Toque em "Baixar para Android" acima
  2. Abra o arquivo baixado (o Android pode pedir para autorizar "instalar de fontes desconhecidas" — é normal)
  3. Toque em Instalar
O Amigos Dr Candido para iPhone funciona como um app instalado na tela de início, sem precisar passar pela App Store.
